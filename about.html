About This Tool

This site provides a frequency-ranked study reference for Chinese characters. Each entry includes the character, pinyin reading, example sentences, and English definitions. Characters are ordered by frequency of use, making it an effective tool for progressive vocabulary acquisition.

Features include:

  • Search by character, pinyin, or English definition
  • Text-to-speech for individual entries and full-page playback
  • Study mode — hide pinyin and English to test recall
  • Dark mode support
  • Load custom datasets from local JSON files

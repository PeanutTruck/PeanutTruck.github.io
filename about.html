About This Tool

A frequency-ranked study reference for Chinese characters, built to support progressive vocabulary acquisition. Each entry includes the character, pinyin reading, example sentences, and English definitions.

Character List

Browse a full dataset of characters ordered by frequency. Search by character, pinyin, or English to quickly find what you're looking for. Each page displays a grid of characters alongside a detail table with pinyin, examples, and one-click text-to-speech for every entry.

Worksheets

Create, edit, and save your own custom character worksheets. Each worksheet is organized into pages of up to eight characters. Switch between View mode (character grid with detail table) and Edit mode (direct text input). Worksheets persist in your browser and can be exported to or imported from JSON files for sharing or backup.

Features

  • Search by character, pinyin, or English definition
  • Text-to-speech for individual entries and full-page grid playback
  • Study mode — hide pinyin and English to test recall
  • Custom worksheets with edit/view modes and JSON import/export
  • Dark mode support with persistent preference
  • Load custom datasets from local JSON files
